# Public distribution status

This is a source/skill distribution, not a snapshot of a user's running system.
No runtime PIDs, device addresses, session IDs, personal courses or evidence
artifacts are distributed. Check actual installed services before any live work.

Implemented: raw capture/ACK backfill; clocks; geometry candidate indexing;
source-preserving workbooks/native background packaging; immutable bindings;
current-chat review; local knowledge and submission/feedback queues.

Remaining: some coordinates unknown; incomplete final undo/eraser/lasso object
state; recognition/grouping uncertainty; new exercise tablet bindings; long-term
and login recovery validation. No autonomous chat wakeup or local persistent LLM.

Begin with `docs/WORKFLOW.md` and `docs/RUNBOOK.md`. Skill installation:
`scripts/install_skill.ps1`. Maintainers' private experiments are deliberately
excluded; never treat missing evidence as a passed device test.
