# 学习流程

1. 指定本地原题，核对裁切与题号，保存来源 hash、页/区域；生成大块留白题册。
2. 将 PDF 背景封装为 `.hinote`，传入公共 Docs，用户自行导入 Notes。
   Notes 可能重建 UUID，按真实曝光/导出建立不可变绑定，不按标题/顺序猜页。
3. 电脑检查已有 receiver、pipeline、course runtime；用户亲自开始并授权采集。
4. 原始笔/手指事件持久化并 ACK，断连按字节回补；独立记录时钟及几何候选。
5. 前后曝光、页面身份与支持域生成页面坐标；运动/工具/上下文失败保留 unknown。
6. 按题产生不可变证据与核图包，当前聊天逐图核对文字、公式、图形、标注。
7. 经已有校验入口保存渐进提示或批阅；知识库呈现来源、建议、参考解答和补强提交。
8. 用户停止，数字收尾审计；不补拍停后画面充当书写证据。

`output/ink/sessions` 为不可改写 raw；`output/pipeline` 为派生坐标/数字审计；
`output/learning` 为本机课程、绑定、队列和历史；`materials` 为用户原件。
这些内容不随克隆提供。当前聊天需要用户调用，不能承诺自动响应。

skill 入口和更具体的 CLI 路由在 `skills/inkbridge-study/`。
